# Omarchy Phone

*Vox Libertatis*

Omarchy (opinionated Arch Linux + Hyprland) adapted for small form factor devices: smartphones.

- `shell/` — the phone shell for Hyprland (home screen, status bar, pull-down, app switcher, lock).
- `apps/phone/` — the phone app: calling over Wi-Fi via a messaging/VoIP service, contacts,
  call screening, groups, voice/video.
- `docs/` — design docs.

First target device: iPhone 6s running HoolockLinux (see github.com/modpunk/Omarchy-iPhone6s):
750x1334 panel at scale 2 (375x667 logical), 2 cores, 2 GB RAM, software rendering only.
